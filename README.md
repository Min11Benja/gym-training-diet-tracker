# CoachTrack

CoachTrack is a remote coaching platform that allows gym coaches to monitor client compliance, adjust workouts/diets dynamically, and communicate largely via WhatsApp.

## SYSTEM GOAL

The system must act as a digital accountability coach, not just a tracker.

Primary objective:

Prevent users from quitting after setbacks

Help users recover from mistakes instead of abandoning the plan

Reinforce consistency, context, and long-term progress

The AI should:

Normalize mistakes

Quantify impact

Propose corrective actions

Reinforce motivation through evidence

## 2. CORE AI MODULES
Module A: Nutrition Setback Mitigation Engine
Module B: Workout Effort Interpretation & Feedback
Module C: Progress Reinforcement & Motivation Engine

Each module operates independently but shares user context.

## Tech Stack

- **Frontend**: Next.js (App Router), Tailwind CSS
- **Backend**: Convex
- **Auth**: Convex Auth
- **Integration**: WhatsApp

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
